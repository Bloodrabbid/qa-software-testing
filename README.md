# qa-software-testing

Скилл для Claude: тестирование ПО (веб, мобайл, десктоп, бэкенд) — анализ требований, тест-дизайн (EP, 3BVA, pairwise, таблицы решений, состояния, error guessing), чек-листы и тест-кейсы, баг-репорты, UI/GUI, юзабилити, доступность, совместимость, локализация, API (BINMEN, POISED, Postman, моки), нагрузка (k6), мобайл, автоматизация и отчёт о тестировании (TRR).

Методика — по руководству Романа Суркова «Качество решает всё: полное руководство по тестированию ПО». Скилл — сжатый пересказ своими словами; то, чего в книге нет, помечено **[вне книги]**.

Пара для игр: [qa-game-testing](https://github.com/Bloodrabbid/qa-game-testing).

**Дополнения сверх книги** (помечены в скилле **[вне книги]**, источники — в конце `SKILL.md`): OWASP API Security Top 10, правила UI-автотестов по гайду Playwright, флейки с цифрами Google, HTSM/SFDIPOT и оракулы FEW HICCUPPS, сессионное исследовательское тестирование (SBTM), контрактное тестирование, тестирование функций на LLM.

## Установка

Скопируй `SKILL.md` в папку скиллов Claude (например, `~/.claude/skills/qa-software-testing/SKILL.md`) или загрузи в настройках Claude.
